# Технологический стек проекта: Wildberries AI Assistant (MVP)

Данный документ определяет финальный перечень технологий, утвержденных для разработки первой версии (MVP) веб-приложения для селлеров Wildberries.

## 1. Frontend (Клиентская часть)
* **Фреймворк:** `Next.js` (App Router) + `React` + `TypeScript`. Обеспечивает высокую производительность и SEO-оптимизацию.
* **Стилизация и UI:** `Tailwind CSS` + `shadcn/ui`. Позволяет быстро собирать профессиональные интерфейсы на базе готовых компонентов.
* **Управление состоянием (State Management):** `Zustand`. Легкий и масштабируемый инструмент для работы с глобальным состоянием (например, настройки чата или UI-флаги).
* **Работа с данными и кэширование:** `React Query` (`TanStack Query`). Используется для взаимодействия с API, поллинга статусов асинхронных задач и управления серверным состоянием.
* **Визуализация данных:** `ECharts`. Выбран для отрисовки высоконагруженных графиков и дашбордов через Canvas/WebGL.
* **Инструментарий ИИ:** `Vercel AI SDK` (`@ai-sdk/react`). Обеспечивает стриминг ответов ИИ в реальном времени и поддержку Tool Calling.
* **Формы и валидация:** `React Hook Form` + `Zod`. Гарантирует типобезопасность и быструю обработку пользовательского ввода (например, API-ключей).
* **Работа с датами:** `date-fns`. Критично для корректного отображения временных интервалов аналитики Wildberries.
* **Иконки:** `Lucide React`.

## 2. Backend (Серверная часть)
* **Фреймворк:** `FastAPI`. Асинхронный Python-фреймворк, обеспечивающий высокую скорость обработки запросов и автоматическую документацию (Swagger).
* **Валидация и контракты:** `Pydantic v2`. Строгая типизация данных на входе и выходе API.
* **ORM и миграции:** `SQLAlchemy` + `Alembic`. Надежная работа с реляционной базой данных.
* **Безопасность:**
    * `SlowAPI` для защиты от Rate-limiting (DDoS/спам).
    * Аутентификация через токены (интеграция с фронтом).
    * CORS Middleware для изоляции доступа.

## 3. Базы данных и Хранение (Insforge Infrastructure)
* **Основная БД:** `PostgreSQL` (через **Insforge**).
    * **RLS (Row Level Security):** Строгая изоляция данных селлеров на уровне БД.
* **Векторная БД:** `pgvector` (встроено в Insforge PostgreSQL).
    * Используется для RAG (Retrieval-Augmented Generation) по документации Wildberries и инсайтам.
    * **Модели:** `intfloat/multilingual-e5-large` (эмбеддинги) + `bge-reranker-base` (реранжирование).
* **Кэш и временные данные:** `Redis Stack`. Хранение «горячих» данных из WB API (TTL 20-30 минут) и семантическое кэширование запросов к LLM.

## 4. AI и Мультиагентная система
* **Оркестрация агентов:** `CrewAI`. Создание графов ролей (Оркестратор, Сборщик данных, Финансовый аналитик, Аналитик склада).
* **LLM Интеграции:** API-агрегаторы (OpenRouter) с паттерном **Fallback** (автоматическое переключение при сбоях основной модели).
* **Кэширование ИИ:** Redis-based семантический кэш для экономии токенов и ускорения ответов на типичные вопросы.

## 5. Фоновые задачи и Очереди
* **Брокер сообщений:** `RabbitMQ`.
* **Выполнение задач:** `Celery`.
* **Планировщик:** `Celery Beat`. Регулярный опрос WB API для обновления данных (с учетом лимитов Token Bucket).

## 6. Infrastructure и DevOps
* **Контейнеризация:** `Docker` + `Docker Compose`.
* **Деплой:** `CapRover` (на арендованный VPS). Обеспечивает Zero-Downtime деплой и удобное управление контейнерами.(времено нет,на страте используем локально все ,деплой через insforge на старте)
* **CI/CD:** `GitHub Actions`.
* **Мониторинг:** `Sentry` (ошибки), `Prometheus` + `Grafana` (метрики), `Loki` (логи).
