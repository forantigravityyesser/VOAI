# 🌐 Глобальная архитектура проекта: Wildberries AI Assistant (VOAI)

## 1. Архитектурная философия: Onion Architecture (Луковичная архитектура)

Проект строится на принципах **Onion Architecture**, что обеспечивает высокую степень разделения ответственности, независимость бизнес-логики от внешних инструментов (БД, API, UI) и легкость тестирования.

### Структура слоев (Layers):

1.  **Core (Внутренний слой / Domain):**
    *   **Расположение:** `src/core`
    *   **Содержание:** Сущности бизнеса (`Seller`, `Order`, `Product`), интерфейсы репозиториев, константы и базовые типы.
    *   **Правило:** Не зависит ни от одного внешнего слоя. Содержит только "чистую" логику бизнеса (например, формулы расчета маржинальности).

2.  **Application Layer (Слой приложения):**
    *   **Расположение:** `src/features/*/services`
    *   **Содержание:** Use Cases (сценарии использования), оркестрация ИИ-агентов, логика обработки специфических данных.
    *   **Зависимости:** Зависит только от Core.

3.  **Infrastructure Layer (Инфраструктура):**
    *   **Расположение:** `lib/`, интеграции с API Wildberries, работа с InsForge (BaaS), адаптеры для внешних сервисов.
    *   **Содержание:** Реализация интерфейсов из Core (например, Concrete Repository), работа со специфическими SDK.

4.  **Presentation Layer (Слой представления):**
    *   **Расположение:** `src/app` (роутинг), `src/features/*/containers` и `src/features/*/views`.
    *   **Содержание:** UI-компоненты (React/Next.js Core), обработка пользовательского взаимодействия, отображение данных.

---

## 2. Модульная организация (Feature-Based Structure)

Весь функционал разделен на независимые модули (фичи) в директории `src/features`. Каждый модуль следует внутреннему паттерну:
*   `index.ts` — публичное API модуля.
*   `containers/` — умные компоненты (бизнес-логика + данные).
*   `views/` — глупые/презентационные компоненты (дизайн + верстка).
*   `services/` — логика обработки данных и взаимодействия с API.
*   `types/` — специфические типы модуля.

**Ключевые модули:**
*   `finance`: Анализ P&L, Unit-экономика, SKU-матрица.
*   `warehouse`: Здоровье склада, планирование поставок.
*   `team`: Управление задачами (Kanban), календарь, командные чаты.
*   `chat`: Глобальный ИИ-ассистент с контекстным анализом.

---

## 3. Мультиагентная ИИ-система

Сердце проекта — оркестрируемая система ИИ-агентов:
*   **Chief Orchestrator:** Анализирует запрос и распределяет подзадачи.
*   **Hermes-agent (Subagents):** Специализированные агенты, работающие на разных LLM моделях для повышения точности ответов.
*   **Data Fetcher:** Отвечает за актуальность данных.
*   **Financial Analyst:** Финансовый аудит и поиск аномалий.
*   **Warehouse Analyst:** Оптимизация товарных остатков.

---

## 4. Технологический стек & Инфраструктура

*   **Frontend:** Next.js 16 (App Router), React 19.
*   **Стилизация:** Tailwind CSS v3.4 (современные утилиты).
*   **Backend-as-a-Service:** InsForge (Auth, DB, Storage, Functions).
*   **Интеграция:** Wildberries API (обработка лимитов, семантическая валидация данных).
*   **Дизайн-система:** *Ethereal Arch* (Glassmorphism, Dark Mode, премиальный UX).

---

## 5. Контур безопасности

*   **RLS (Row Level Security):** Разграничение доступа к данным на уровне БД (каждый селлер видит только свои данные).
*   **Secret Management:** Зашифрованное хранение API-ключей Wildberries.
*   **Metadata Validation:** Предварительная проверка данных перед отправкой в WB API для сохранения лимитов запросов.
