# 🚀 Инфраструктура и Деплой

## 🏗 Инфраструктурный ландшафт

Проект использует гибридную инфраструктуру, сочетающую локальную разработку и облачные сервисы **InsForge** для обеспечения BaaS (Backend-as-a-Service).

### Основные компоненты:
1.  **Хостинг & Backend:** [InsForge](https://insforge.app). Обеспечивает:
    *   Управляемую базу данных PostgreSQL.
    *   Auth-сервис (регистрация и вход пользователей).
    *   Storage (хранилище файлов).
    *   AI Edge Functions (выполнение серверной логики).
2.  **API Gateway:** FastAPI сервер (проксирует запросы к Wildberries и выполняет тяжелую оркестрацию ИИ-агентов).
3.  **Frontend Hosting:** На этапе MVP планируется деплой через InsForge Hosting или Vercel (Next.js).

---

## 🛠 Процесс разработки (Local)

Для запуска проекта локально используются следующие шаги:
```bash
# Установка зависимостей
npm install

# Запуск dev-сервера Next.js
npm run dev
```

### Переменные окружения (.env):
*   `INSFORGE_URL`: URL бекенда от InsForge.
*   `INSFORGE_ANON_KEY`: Ключ для публичного доступа к SDK.
*   `WB_API_KEY`: Тестовый ключ для интеграции с маркетплейсом.

## 🚢 Деплой (Deployment Flow)

### 1. Подготовка (Pre-flight checks)
Перед деплоем запускается автоматический чек-лист:
*   `npm run lint`: Проверка качества кода.
*   `npm run build`: Проверка сборки Next.js.
*   Валидация схем БД в InsForge.

### 2. Деплой фронтенда
Выполняется с помощью MCP-инструментов InsForge:
```powershell
# Пример команды деплоя
npx insforge deploy
```

### 3. Автоматизация (CI/CD)
Используется **GitHub Actions**:
*   **Main branch:** Автоматический линтинг и запуск тестов при каждом Push.
*   **Release:** Автоматический деплой в продакшн-окружение InsForge при создании тега.

---

## 📊 Мониторинг и Логирование
Для обеспечения стабильности системы используются:
*   **Sentry:** Сбор и анализ ошибок на фронтенде и бекенде.
*   **Prometheus + Grafana:** Мониторинг системных метрик и производительности.
*   **Loki:** Централизованный сбор логов контейнеров.
*   **InsForge Logs:** Отслеживание работы Edge Functions и запросов к БД.
