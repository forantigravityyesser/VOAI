# 📁 Структура репозитория

Проект организован по модульному принципу в соответствии с **Onion Architecture**.

## Коренная структура

```text
VOAI/
├── .agent/              # Конфигурации и скрипты ИИ-агентов Antigravity
├── obsidian/            # База знаний проекта (Vault)
├── public/              # Статические ассеты (логотипы, изображения)
├── src/                 # Исходный код приложения
│   ├── app/             # Next.js App Router (Routing & Pages)
│   ├── core/            # Domain Layer (Сущности, Типы, Константы)
│   ├── features/        # Application & Presentation Layer (Модули)
│   ├── lib/             # Infrastructure Layer (Интеграции, SDK, Клиенты)
│   └── shared/          # Shared Layer (Общие компоненты, Hooks, Utils)
├── ARCHITECTURE.md      # Краткий справочник архитектуры
├── PROJECT_OVERVIEW.md  # Обзор миссии и статуса проекта
└── package.json         # Зависимости и скрипты
```

## Подробное описание директорий

### `src/core/`
Центральное ядро. Здесь описываются "правила игры":
*   `types/`: TypeScript интерфейсы для всех моделей данных маркетплейса.
*   `constants/`: Фиксированные значения (ставки налогов, категории, лимиты).
*   `schemas/`: Zod-схемы для валидации данных.

### `src/features/`
Каждая папка здесь — это отдельная функциональная вертикаль.
*   `finance/`: Все, что связано с деньгами.
*   `warehouse/`: Логистика и остатки.
*   `team/`: Kanban, календарь и управление сотрудниками.
*   Каждая фича содержит свои `containers` (логика) и `views` (отображение).

### `src/shared/`
Общий инструментарий, используемый во всех фичах:
*   `components/`: UI-кит (кнопки, инпуты, карточки в стиле Ethereal Arch).
*   `hooks/`: Общие React хуки (useAuth, useAPI).
*   `utils/`: Чистые функции-помощники.

### `src/app/`
Слой маршрутизации. Здесь находятся страницы (`page.tsx`), которые импортируют контейнеры из `features/`. Логика в самих файлах `page.tsx` сведена к минимуму.
