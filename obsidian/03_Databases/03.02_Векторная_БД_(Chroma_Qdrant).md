# 🧠 Векторная БД (pgvector)

Хотя в индустрии популярны Chroma и Qdrant, в проекте VOAI используется расширение **pgvector** для PostgreSQL. Это позволяет хранить векторы (эмбеддинги) в той же базе, что и реляционные данные, обеспечивая консистентность и упрощая архитектуру.

## 1. Схема векторных таблиц

### Таблица `knowledge_base` (База знаний RAG)
*   **`id`**: UUID (Primary Key)
*   **`content`**: Text — Сырой текст (документация WB, правила API, статьи оферты).
*   **`metadata`**: JSONB — Информация об источнике, дате парсинга и версии документа.
*   **`embedding`**: Vector(1024) — Векторное представление текста, созданное моделью `intfloat/multilingual-e5-large`.

### Таблица `ai_insights_cache` (Кэш инсайтов ИИ)
*   **`id`**: UUID (Primary Key)
*   **`context_hash`**: String — Хэш-сумма данных, по которым был сгенерирован инсайт.
*   **`insight_text`**: Text — Сгенерированный ответ ИИ.
*   **`embedding`**: Vector(1024) — Позволяет находить похожие ситуации в данных и переиспользовать ранее сгенерированные советы.

---

## 2. Поиск и Оптимизация
*   **Алгоритм**: Для поиска используется косинусное сходство (Cosine Similarity).
*   **Индексация**: Используется индекс **HNSW** (Hierarchical Navigable Small World) для обеспечения сверхбыстрого векторного поиска даже при росте объема данных.
