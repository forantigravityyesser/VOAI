# 🗄 Реляционная БД (PostgreSQL)

База данных реализована на **PostgreSQL** через инфраструктуру **InsForge**. Она является "источником истины" для всех бизнес-данных и финансовых отчетов.

## 1. Схема таблиц

### Таблица `users` (Пользователи)
*   **`id`**: UUID (Primary Key) — Уникальный идентификатор пользователя.
*   **`email`**: String (Unique) — Электронная почта.
*   **`password_hash`**: String — Хэш пароля.
*   **`created_at`**: Timestamp — Дата регистрации.
*   **`subscription_tier`**: Enum — Уровень подписки (`Free`, `Pro`, `Business`).

### Таблица `shops` (Магазины Wildberries)
*   **`id`**: UUID (Primary Key)
*   **`user_id`**: UUID (Foreign Key -> `users.id`)
*   **`name`**: String — Название магазина для пользователя.
*   **`api_key_base`**: Encrypted String — Токен API WB типа "Стандартный".
*   **`api_key_statistic`**: Encrypted String — Токен API WB типа "Статистика".
*   **`service_secret`**: Encrypted String — Секретный ключ для SaaS-интеграций.
*   **`is_active`**: Boolean — Флаг активности магазина.
*   **RLS Policy**: `WHERE user_id = current_user_id()`

### Таблица `products` (Товары/Номенклатура)
*   **`id`**: UUID (Primary Key)
*   **`shop_id`**: UUID (Foreign Key -> `shops.id`)
*   **`nm_id`**: BigInt — Идентификатор WB (Nomenclature ID).
*   **`vendor_code`**: String — Артикул продавца.
*   **`subject_id`**: Int — ID предмета/категории.
*   **`brand`**: String — Бренд товара.
*   **`title`**: String — Наименование товара.
*   **`base_price`**: Decimal — Базовая цена до скидок.
*   **`current_discount`**: Int — Текущая скидка в процентах.
*   **`kiz_marked`**: Boolean — Требуется ли маркировка Честный Знак.

### Таблица `warehouse_stocks` (Остатки на складах)
*   **`id`**: UUID (Primary Key)
*   **`product_id`**: UUID (Foreign Key -> `products.id`)
*   **`warehouse_name`**: String — Название склада WB.
*   **`quantity`**: Int — Доступное количество.
*   **`in_way_to_client`**: Int — Товары в пути к покупателю.
*   **`last_updated`**: Timestamp — Время последнего обновления остатков.

### Таблица `financial_reports` (Финансовая аналитика)
*   **`id`**: UUID (Primary Key)
*   **`shop_id`**: UUID (Foreign Key -> `shops.id`)
*   **`rrd_id`**: BigInt — Номер записи в отчете реализации WB.
*   **`sale_date`**: Date — Дата продажи.
*   **`revenue`**: Decimal — Выручка (до вычетов).
*   **`commission`**: Decimal — Комиссия маркетплейса (КВВ).
*   **`logistics_cost`**: Decimal — Стоимость логистики.
*   **`storage_cost`**: Decimal — Стоимость хранения.
*   **`penalties`**: Decimal — Штрафы и доплаты.
*   **`net_profit`**: Decimal — Чистая прибыль после всех вычетов.

---

## 2. Индексация
*   **B-Tree**: Для полей PK, FK и дат (`sale_date`, `created_at`).
*   **BRIN**: Для оптимизации запросов по очень большим временным рядам в таблице финансовых отчетов.
*   **GIN**: Для полнотекстового поиска по названиям товаров и метаданным.
