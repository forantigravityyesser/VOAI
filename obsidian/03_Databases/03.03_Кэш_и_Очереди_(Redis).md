# ⚡ Кэш и Очереди (Redis & RabbitMQ)

Этот раздел описывает технологии для управления временными данными, кэширования ответов ИИ и обработки фоновых задач.

## 1. Redis (Кэширование)
Используется **Redis Stack** для нескольких критических задач:

*   **API Cache:** Кэширование "горячих" ответов от Wildberries API (Stock, Prices) с TTL 20-30 минут для экономии лимитов запросов.
*   **Semantic Cache:** Хранение результатов запросов к LLM. Перед отправкой запроса к ИИ проверяется, нет ли в Redis похожего по смыслу ответа.
*   **Session Store:** Хранение состояний активных сессий пользователей.

## 2. RabbitMQ & Celery (Фоновые задачи)
Используется для обработки длительных операций, которые не должны блокировать UI:

*   **RabbitMQ:** Брокер сообщений, координирующий очередь задач.
*   **Celery Workers:** Обработчики, выполняющие:
    *   Регулярную синхронизацию данных с WB API.
    *   Генерацию тяжелых PDF-отчетов.
    *   Рассылку уведомлений.
*   **Celery Beat:** Планировщик, инициализирующий задачи по расписанию (например, опрос лимитов складов каждый час).
