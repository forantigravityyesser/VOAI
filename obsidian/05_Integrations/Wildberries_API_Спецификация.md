# Wildberries API: Спецификация 2026

Синтезированный обзор архитектуры и интеграционных паттернов Wildberries API на основе данных 2026 года.

## Ключевые архитектурные концепции
- **Стиль**: REST API (JSON over HTTP).
- **Безопасность**: JWT и OAuth 2.0. Принцип наименьших привилегий (4 типа токенов).
- **Согласованность**: Eventual Consistency. Данные аналитики могут обновляться с задержкой 30-60 минут.
- **Интеграция SaaS**: Внедрен контур **Service Secret** (`X-Client-Secret`) для изоляции лимитов.

## Типы токенов (2026)
| Тип | Назначение | Особенности |
| :--- | :--- | :--- |
| **Base** | Стандартный | Доступ к контенту и логистике. Срок 180 дней. |
| **Test** | Sandbox | Изолированная среда, фиктивные данные. |
| **Personal** | On-premise | Для внутренних систем (например, 1С). |
| **Service** | SaaS/Cloud | Привязан к OAuth 2.0. |

## Управление нагрузкой (Rate Limiting)
Алгоритм **Token Bucket**.
- **Штрафы**: Ошибка 409 списывает сразу 10 запросов из лимита.
- **Стратегия**: Exponential Backoff + Jitter.

## Финансовая модель (Pay-as-you-go)
- **By Entity Count**: Списание за количество карточек.
- **By Method Call**: Списание за вызов транзакционного метода.
